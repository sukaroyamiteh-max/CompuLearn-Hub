Computer Basics

Learn how computers receive input, process information, store data, and produce output.

The CPU processes instructions, while RAM temporarily holds data and programs currently being used.
📁

Files & Folders

Organize schoolwork so it is easy to find and protect.

Use clear filenames, folders by subject, regular backups, and avoid deleting unfamiliar files.
🌐

Internet Basics

Understand browsers, websites, searches, and responsible online use.

A browser accesses websites. Check information using reliable sources and protect private information.
📝

Productivity Tools

Use documents, presentations, and spreadsheets effectively.

Plan your work, use consistent formatting, save regularly, and review before submitting.
🛡️

Cyber Safety

Build safer habits on school computers and online accounts.

Use strong unique passwords, update software, avoid suspicious links, and sign out of shared computers.
🔧

Hardware Care

Learn simple ways to protect computers and peripherals.

Keep liquids away, handle cables carefully, keep vents clear, and report damaged equipment.

Quick Troubleshooting

Basic checks before asking for technical support.

🐌 Slow Computer

Try: close unused programs, restart, check storage, and report repeated slow performance.

📶 No Internet

Try: check network status, reconnect if allowed, test another site, then report the issue.

⌨️ Mouse/Keyboard

Try: check the connection, try another port if permitted, and report damaged peripherals.
